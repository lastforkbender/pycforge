# Security Policy

## Supported version

Security fixes are provided for the latest public PyCForge release.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting or Security Advisory
facility for `lastforkbender/pycforge`. Do not disclose a suspected
vulnerability in a public issue before a fix and coordinated disclosure are
available.

Include the affected PyCForge and Python versions, operating system, a minimal
reproduction, and the security impact. Do not include secrets or sensitive
source material in the report.
