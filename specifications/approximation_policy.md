# Approximation Allowlist Policy — Candidate 0.1

Approximations are disabled by default. Permission is granted only by exact stable approximation code. There is no broad approximate mode.

Each future approximation entry must declare construct, eligibility preconditions, exact semantic delta, severity, visible marker, affected profiles, RulePlan ownership, and boundary fixtures. Missing permission makes the approximation rule ineligible.

The first milestone defines no approximation codes and must either convert directly or reject.
