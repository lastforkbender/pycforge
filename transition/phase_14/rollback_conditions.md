# Phase 14A Rollback Conditions

Before promotion, abandon the Phase 14A candidate and restore the authenticated
PyCForge 0.13.0 release if any condition below occurs:

## Candidate-abandon triggers

- the sealed v0.13.0 source archive, canonical release tree, converter subtree,
  wheel, roadmap, addendum, helper registry, or either helper asset cannot be
  reproduced at its recorded identity;
- any `//` or `%` occurrence reaches a RulePlan without exact integer operand
  categories and the complete directly proved literal-divisor fact;
- a divisor of `0`, `-1`, or `INT64_MIN`, an out-of-domain integer, Boolean,
  dynamic divisor, or another excluded form selects a helper or reaches C IR;
- special lowering, unsigned conversion, text injection, or a new C IR form is
  introduced to repair the rejected `INT64_MIN` divisor spelling;
- accepted semantics require a runtime zero check, arithmetic exception,
  overflow channel, arbitrary-precision representation, allocation, cleanup,
  global state, or hidden approximation;
- the frozen helper code, structured C IR factories, versions, contracts,
  fingerprints, registry membership, or target list changes;
- evaluation of a dividend is duplicated, reordered, conditionally moved, or
  inferred during rendering;
- an implementation adds a new Python grammar form, C IR node kind, statement
  form, binding form, numeric operator, or another Phase 14 feature without a
  separately approved decision;
- rejected or cancelled conversion publishes partial facts, plans, helper
  manifests, mappings, traces, summaries, telemetry-derived semantics, C IR,
  or generated C;
- predecessor-compatible source without an eligible 14A operator changes its
  generated-C bytes or output fingerprint without an explicit reviewed schema
  cause;
- deterministic ordering, independent validation, provenance, diagnostic
  stability, resource ceilings, cancellation responsiveness, observer
  isolation, module closure, record/container ownership, workspace stale-output
  protection, atomic save, or package installation regresses;
- a test, audit, validator, evidence collector, review, or packaging gate
  compiles, links, loads, or executes generated C;
- promotion is attempted with an unowned High or Extreme conversion-debt item,
  an unmet budget, incomplete vertical evidence, or an unsealed predecessor.
